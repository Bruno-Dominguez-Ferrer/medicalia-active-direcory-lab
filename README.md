Medicalia Active Directory Lab

A Windows Server 2022 infrastructure lab focused on deploying and managing a centralized IT environment using Active Directory Domain Services.

Project overview

This project simulates the IT infrastructure of a fictional healthcare company called Medicalia.

The main objective is to deploy a Windows Server environment to centralize user and computer management, implement security policies, configure shared resources and provide centralized authentication.

The project is being developed as part of my Systems Administration studies (ASIR) and as a practical infrastructure portfolio project.
